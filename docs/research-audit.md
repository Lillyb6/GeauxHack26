# Scientific audit / remaining validation work

2026-10-23. This audit improves traceability; it does not establish complete scientific validity.

| Area | Evidence now | What still must happen |
|---|---|---|
| Environment | NASA field references and units | Choose site/altitude/season, variability and time profiles |
| Crew | Consistent NASA reference baseline | Activity/crew variability and complete water/CO2/food balance |
| Electrolyzer | Chemistry + DOE terrestrial energy proxy | Select actual hardware; operating limits, efficiencies and losses |
| Recycler | Historical ISS load and demonstrated ISS recovery context | Coupled throughput/power/recovery curves and off-Earth applicability |
| Habitat loads | Explicit editable unvalidated design inputs | Itemized equipment power budget with manufacturer/research specs |
| Thermal | NASA equation basis; unvalidated UA/COP | Geometry, materials, radiation/convection, internal heat, HVAC/heat rejection |
| Radiation/pressure | Marked unevaluated | Environmental doses, shielding response, atmosphere/structure models |
| System outcomes | Deterministic mass/energy accounting | Independent calibration against reference cases and uncertainty analysis |

Until resolved, describe this as a research-informed resource-balance prototype, not a NASA-validated survival predictor. Do not optimize against the current equations and call the answer safe.

Contribution rule: every new physical constant must have a source ID, units, exact table/page/section, reference context and applicability note. Every derived value needs its equation. Every design input must say it is a design input. Avoid treating future targets as demonstrated performance. Test units and reference-default consistency. Review the model, not just whether tests pass.
